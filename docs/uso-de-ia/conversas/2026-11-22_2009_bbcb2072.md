O IP vem da interface Wi-Fi (`wlo1`) deste PC. Para abrir direto num slide, acrescente `#5` à URL.

As fontes do Google só carregam se o celular tiver internet. Sem rede, o navegador usa as fontes de reserva.

No celular, as setas e a tecla F não existem. Se a navegação por toque não funcionar, use o teclado no PC para passar os slides.
