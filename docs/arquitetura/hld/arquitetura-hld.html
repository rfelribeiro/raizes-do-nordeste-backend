Tudo o que roda, numa figura só

Cada caixa azul é um contêiner Docker: um programa isolado, com tudo de que precisa, que sobe igual em qualquer computador. Quem avalia o projeto roda os mesmos comandos make e obtém o mesmo resultado.

No celular, arraste o diagrama para o lado para ver tudo.

Cada peça, em uma frase

api

O coração do sistema. Recebe os pedidos dos canais, confere quem está pedindo, controla o estoque e o status do pedido.

db

O banco de dados PostgreSQL. Guarda pedidos, estoque e auditoria, e anota cada acontecimento importante numa caixa de saída de eventos.

gateway-mock

Um simulador da operadora de pagamento. Aprova, recusa ou demora de propósito, para testar como a API reage.

analytics

Copia os eventos novos do banco para arquivos Parquet e monta o Data Warehouse em DuckDB com o dbt, em três camadas.

dashboard

O painel de vendas em Streamlit, para o gestor. Lê só a camada final do Data Warehouse, nunca o banco da operação.

Postman e newman

A coleção de testes da API. Dá para abrir no app do Postman ou rodar inteira pelo newman, sem instalar nada.

Uso pontual

Playwright tira as capturas de tela; mermaid-cli, pandoc e LibreOffice transformam o texto no PDF em normas ABNT.

GitHub

Guarda o código público e, a cada envio, sobe tudo do zero e roda seis verificações automáticas.

Segurança. Só as portas 8080 (API), 5432 (banco) e 8501 (painel) ficam abertas, e apenas para o próprio computador. O simulador de pagamento nem tem porta exposta. Senhas e chaves ficam num arquivo local que nunca vai para o repositório.
